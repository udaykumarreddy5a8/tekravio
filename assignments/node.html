// 01 · The Brief

What You're Building

Tekravio runs sprint-based consulting projects. You're building the Node.js backend for the internal sprint tracker. Same domain as our Java assignment — different stack, different patterns, same standard.

Use Express.js with Sequelize ORM (PostgreSQL or SQLite for dev). Structure it like a production codebase — not a 200-line index.js file.

// The System

A Node.js REST API for Tekravio's sprint tracker. Clients → Projects → Sprints → Tasks → Engineers. Real-time task updates, sprint summaries, and engineer workload management.

03
Validation & Error Handling
// 20 marks · Production Readiness

A production Node API never returns a raw error stack. Handle every failure path gracefully.

✓
Input validation using express-validator or Joi on all POST/PUT routes
✓
Global error handling middleware — catches everything, returns structured error JSON
✓
Custom error classes: NotFoundError, ValidationError, BusinessRuleError
✓
Business rule: unavailable engineer cannot be assigned to a task
✓
Business rule: task status can only move forward — TODO→IN_PROGRESS→REVIEW→DONE
✓
Async error wrapper — no unhandled promise rejections anywhere
middleware/errorHandler.jsJS
const errorHandler = (err, req, res, next) => {
  const status = err.statusCode || 500;
  res.status(status).json({
    success: false,
    message: err.message || 'Internal Server Error',
    errors: err.errors || [],
    timestamp: new Date().toISOString()
  });
};
