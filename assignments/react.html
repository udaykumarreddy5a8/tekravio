// 01 · The Brief

What You're Building

A Sprint Operations Dashboard for Tekravio Studio. Engineering managers use this to monitor projects, track sprint progress, manage tasks, and see engineer workloads in real time.

Use React + TypeScript with TanStack Query for server state and Zustand for client state. No class components. No any types. No inline styles.

// The Mock API

We provide a mock API via json-server or MSW (Mock Service Worker). Set it up in your project. All API calls should hit your mock backend — structure it to match the domain model below.

// 02 · Domain Model

Data Shape — TypeScript Interfaces

types/index.ts — define theseTSX
interface Client { id, name, industry, contactEmail, country, createdAt }
interface Project { id, name, description, status: 'ACTIVE'|'COMPLETED'|'ON_HOLD', startDate, endDate, clientId }
interface Sprint { id, sprintNumber, goal, status: 'PLANNED'|'IN_PROGRESS'|'DONE', startDate, endDate, projectId }
interface Task {
  id, title, description,
  priority: 'LOW'|'MEDIUM'|'HIGH'|'CRITICAL',
  status: 'TODO'|'IN_PROGRESS'|'REVIEW'|'DONE',
  estimatedHours, actualHours, sprintId, engineerId
}
interface Engineer { id, name, email, primaryStack, experienceYears, isAvailable }

02
Core Pages & Components
// 25 marks · Core Delivery

Build 4 pages. Every page fetches real data from your mock API. No hardcoded arrays.

✓
Dashboard — Summary cards: active projects count, tasks in progress, overdue tasks, available engineers. All from API.
✓
Projects Page — List of all projects with status badge, client name, date range. Click to see sprints.
✓
Sprint Board — Kanban-style board: 4 columns (TODO · IN_PROGRESS · REVIEW · DONE). Drag task to update status via API call.
✓
Engineers Page — List of engineers with availability indicator, primary stack badge, active task count.
✓
Task Detail Modal — Click any task to see full details. Edit title, priority. Reassign engineer from available list.
03
Forms, Validation & UX
// 20 marks · Craft Matters

Forms that actually work in production. Loading states that don't freeze the UI. Errors that don't confuse the user.

Create Task form using React Hook Form + Zod schema validation
✓
Create Project form — client dropdown, date pickers, status selector
✓
Loading skeletons (not spinners) on all data-fetching pages

Optimistic UI updates on task status changes — update instantly, rollback on error

Toast notifications for success/error states using react-hot-toast or sonner
✓

04
Sprint Intelligence — Visualised
// 25 marks · Think Like a Product Engineer

Turn raw data into insight. This is what separates a frontend engineer from a UI copier.

✓
Sprint Progress Bar — Visual completion % for each sprint. Colour-coded: red <30%, yellow 30–70%, green >70%.
✓
Task Priority Breakdown — Bar or donut chart showing task count by priority per sprint. Use Recharts or Chart.js.
✓
Engineer Workload View — Each engineer shown with their active task count and a visual workload bar (0–5 tasks = green, 5+ = amber).
✓
Project Health Score — Display the health score from the API as a circular progress indicator. Define the colour thresholds.
✓
Filtering & Search — Filter tasks by status, priority, engineer. Live search on project and engineer names. All client-side, no refetch.
