// 01 · The Brief

What You're Building

The same Tekravio sprint tracker system — built with FastAPI, SQLAlchemy ORM, Pydantic for validation, and Alembic for migrations. Python done properly — not scripting with an API tacked on.

// The System

A FastAPI REST API for Tekravio's sprint tracker. Async endpoints, Pydantic schema validation, SQLAlchemy models with proper relationships, and a clean separation between routers, services, and models.

// 02 · Domain Model

Entities & Relationships

models.py — SQLAlchemy modelsPYTHON
# Define as SQLAlchemy ORM models

Client    — id, name, industry, contact_email, country, created_at
Project   — id, name, description, status ["ACTIVE","COMPLETED","ON_HOLD"]
              start_date, end_date, client_id
Sprint    — id, sprint_number, goal, status ["PLANNED","IN_PROGRESS","DONE"]
              start_date, end_date, project_id
Task      — id, title, description, priority ["LOW","MEDIUM","HIGH","CRITICAL"]
              status ["TODO","IN_PROGRESS","REVIEW","DONE"]
              estimated_hours, actual_hours, sprint_id, engineer_id
Engineer  — id, name, email, primary_stack, experience_years, is_available

02
REST API — CRUD Endpoints
// 25 marks · Core Delivery

Clean async FastAPI endpoints. Proper response models. Every endpoint typed end-to-end.

MethodEndpointDescription
POST/api/clientsCreate client
GET/api/clients?skip=0&limit=10List clients with pagination
GET/api/clients/{id}Get client with their projects
PUT/api/clients/{id}Update client
DELETE/api/clients/{id}Soft delete — set deleted_at
POST/api/projectsCreate project for client
GET/api/projects/{id}/sprintsGet project sprints
POST/api/sprints/{id}/tasksAdd task to sprint
PUT/api/tasks/{id}/statusUpdate task status
PUT/api/tasks/{id}/assign/{engineer_id}Assign engineer to task
✓
Every endpoint has a typed response_model= — Pydantic all the way
✓
Correct HTTP status codes using FastAPI status module
✓
No ORM objects returned directly — always convert to Pydantic schema
✓
Auto-generated Swagger docs work perfectly at /docs
