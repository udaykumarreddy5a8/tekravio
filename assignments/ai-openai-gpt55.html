// The Context
GPT-5.5 is OpenAI's flagship model for agentic coding, computer use, knowledge work, and early scientific research. Released April 23, 2026, it reuses the GPT-5 router architecture across five effort levels (xhigh, high, medium, low, non-reasoning) and ships as GPT-5.5 (default), GPT-5.5 Thinking (all paid plans), and GPT-5.5 Pro (Pro/Business/Enterprise only). It is also deployed as GPT-5.5 Instant — the new ChatGPT default since May 5, 2026, producing 52.5% fewer hallucinated claims than GPT-5.3 Instant on high-stakes prompts in medicine, law, and finance.

The model also powers the 2026 Codex — a fully agentic coding environment in the CLI, IDE extensions, and web, with computer use via screen reading. This is not the 2021 Codex. Every design decision you document should connect to a real production implication.

01
Model Family Architecture & The Router Design
// 20 marks
▼

GPT-5.5 is a family built on a router architecture across effort levels. Document every tier, the structural design, and what the 1.1M context window means in production.

Three consumer tiers: GPT-5.5 (default), GPT-5.5 Thinking (all paid tiers), GPT-5.5 Pro (Pro/Business/Enterprise only). What is each designed for? Why is Pro gated to higher subscription tiers? Explain the capability difference between Thinking and Pro.
Router architecture: GPT-5.5 reuses the GPT-5 family router across five effort levels: xhigh, high, medium, low, and non-reasoning. Explain what a router architecture means for an LLM: how does it differ from a single monolithic model? How does the model decide which effort level to apply?
Context window & long-context pricing: 1.1M context, 128K max output. Prompts above 272K input tokens are charged at 2× input and 1.5× output for the full session (standard, batch, and flex). Work through a specific example: a developer sends a 400K-token prompt. Calculate the cost at standard rate vs long-context rate.
Token efficiency vs GPT-5.4: OpenAI claims GPT-5.5 is more intelligent AND more token-efficient than GPT-5.4. At what efficiency improvement does GPT-5.5's 2× higher price ($5 vs $2.50) become cost-neutral? Show the calculation.
GPT-5.5 Instant as ChatGPT default: Became the default ChatGPT model on May 5, 2026. Produces 52.5% fewer hallucinated claims than GPT-5.3 Instant on high-stakes prompts in medicine, law, and finance. Explain how hallucination rate is measured as a metric, and why a 52.5% reduction is meaningful for enterprise deployments.

02
Codex 2026 & Agentic Coding Capabilities
// 22 marks
▼

GPT-5.5's biggest new deployment is the 2026 Codex — a fully agentic coding environment. This is not the 2021 Codex. Understand exactly what it does and how it compares to every competing coding environment.

What 2026 Codex actually is: An agentic coding environment available in CLI, IDE extensions (VS Code, JetBrains), and web. How does it differ from simply calling the GPT-5.5 API directly? What does it mean for Codex to be 'agentic' vs a standard completion API?
400K context in Codex vs 1M in API: Codex uses a 400K context window while the API supports 1.1M. Why are they different? What specific agentic coding tasks break at 400K that would work at 1M?
Terminal-Bench 2.0 at 82.7%: GPT-5.5 scores 82.7% on Terminal-Bench 2.0 vs Claude Opus 4.7 at 69.4% and Gemini 3.1 Pro at 68.5%. What does Terminal-Bench 2.0 actually test? Why is this benchmark specifically relevant to agentic coding? What does 82.7% mean in terms of which tasks the model can reliably complete?
Computer use in Codex: GPT-5.5 supports screen-reading computer use in Codex. Define computer use. How does it differ from function calling? Which plan tiers support it? What are the current practical limitations?
Codex pricing tiers: Fast mode: 1.5× faster, 2.5× cost. Batch/Flex: 0.5× standard rate. Priority: 2.5×. When does each tier make economic sense? For a startup running 50,000 code-review tasks per month, calculate the cheapest viable tier and total monthly cost.
GPT-5.5 vs Cursor vs GitHub Copilot: Cursor uses Claude Fable 5 (state-of-the-art on CursorBench per Cursor's CEO). GitHub Copilot runs GPT-5.5. OpenAI's own Codex runs GPT-5.5. Document the overlap and differentiation between all three coding environments — capability, pricing, and which developer profile each suits.

// 02 · Design Questions
Answer These in Your README

Short, precise answers. Vague answers score zero. We will ask follow-ups on every answer in the review call.

Q1
A client sends 50,000 API requests per day averaging 800 input tokens and 400 output tokens. At $5/$30 per million tokens, what is their monthly cost? At what point does a ChatGPT Enterprise subscription become cheaper than pure API?
Q2
GPT-5.5 and Claude Fable 5 both have safety mechanisms. GPT-5.5's system card mentions additional safeguards for cybersecurity queries. Fable 5 uses classifiers that return stop_reason: 'refusal' (HTTP 200) and fall back to Opus 4.8. For a Tekravio Studio client building a security audit tool, which model's safety approach is less likely to interfere with legitimate use? Justify your answer.
Q3
Codex runs on a 400K context window while the GPT-5.5 API supports 1.1M. A developer wants to run an agentic code review across an entire 600K-token codebase. What is the recommended approach — Codex, direct API, or something else? What breaks at 400K tokens?
Q4
OpenAI's release notes flag memorization on at least one benchmark. If a model has memorized the answers to an eval, what does that tell you about the reliability of that benchmark score as a capability predictor? How should you adjust your evaluation when choosing between GPT-5.5 and a competing model?
