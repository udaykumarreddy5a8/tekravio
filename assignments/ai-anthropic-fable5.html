// The Context
On June 9, 2026, Anthropic launched two of the most significant AI models in the company's history. Claude Fable 5 is a Mythos-class model made safe for general use — the first time Mythos-level capabilities have been available to the public. Claude Mythos 5 is the same underlying model with safety classifiers lifted in specific areas, available only to approved organisations through Project Glasswing.

Fable 5 leads on SWE-bench Verified at 95% and is state-of-the-art on CursorBench and FrontierCode. Mythos 5 enables drug design at 10× acceleration and produces novel scientific hypotheses. Both models have adaptive thinking always-on and never return raw thinking content. They carry a 30-day data retention requirement as Covered Models. Assignment 08 is the synthesis assignment: document Anthropic fully, then build the master 8-model comparison.

01
Fable 5 vs Mythos 5 — Same Weights, Different Safeguards
// 20 marks
▼

The core Anthropic distinction. Both models share the same underlying weights. What separates them is entirely safeguards and access. Document with precision.

Complete specs table: Side-by-side table for Fable 5 vs Mythos 5: API model ID, context window, max output tokens, pricing (input + output per million tokens), adaptive thinking status, whether raw thinking is returned, data retention policy, availability (general vs Glasswing), and safety classifiers (on vs off for Fable vs Mythos).
Safety classifier architecture: Fable 5 runs a separate AI classifier system that intercepts before the main model responds. Three blocked domains: cybersecurity, biology/chemistry, and distillation. When a classifier triggers, the API returns stop_reason: 'refusal' as HTTP 200 — not an error code. Explain why this design choice (HTTP 200 rather than 4xx) matters for application code.
Three fallback options: When Fable 5 refuses, the request can be retried on Claude Opus 4.8 via three paths: (1) server-side via the fallbacks parameter (beta on Claude API and Claude Platform on AWS), (2) client-side via SDK middleware (TypeScript, Python, Go, Java, C#), (3) manual retry. What is 'fallback credit' and how does billing work when a fallback occurs?
Adaptive thinking always-on: Fable 5 and Mythos 5 have adaptive thinking always enabled. thinking: {type: 'disabled'} is not supported. The thinking.display setting controls what thinking blocks contain: 'summarized' (readable summary) vs 'omitted' (empty field). For a production customer-facing application, which display setting should you use and why?
30-day data retention as Covered Models: Both models carry a mandatory 30-day data retention requirement and are not available under zero data retention. Research what 'Covered Model' means in Anthropic's data policy. For which specific enterprise customer types (HIPAA, SOC 2 Type II, ISO 27001 in specific industries) does this become a procurement blocker? What alternatives do those customers have?

Answer in Your README

Four questions. Some require calculations across multiple models.

Q1
A Studio client wants to build a code migration tool that automatically updates a 2M-line Java codebase from Java 11 to Java 17+. They need to process the entire codebase as context. Which models can handle 2M tokens? Of those, which has the strongest Java coding capability? Design the architecture including any chunking strategy if needed.
Q2
Fable 5 costs $10/$50. Gemini 3.1 Pro costs $2/$12. A product manager argues: 'For our document analysis use case, Gemini is 5× cheaper and scores 94.3% on GPQA Diamond vs Fable 5's performance. We should use Gemini.' Your engineering lead says: 'But Fable 5 is better at complex multi-step reasoning and has better context retention.' Build the analysis: which model wins for a 500K-token financial report analysis with 20 complex analytical questions?
Q3
Anthropic claims 95%+ of Fable 5 sessions involve no classifier fallback. For a company running 1 million API requests per month, that means approximately 50,000 requests per month fall back to Opus 4.8. Design the application architecture that handles this fallback gracefully: response time impact, cost implications (fallback credit), logging, and user experience. What monitoring would you put in place to detect if the 5% rate is changing?
Q4
You are presenting to Uday: 'Should Tekravio sign a 12-month enterprise contract with Anthropic for Claude Fable 5 at a negotiated discount, or maintain pay-as-you-go flexibility to switch to GPT-5.5, Gemini 3.1 Pro, or the next Grok/DeepSeek as the landscape evolves?'
