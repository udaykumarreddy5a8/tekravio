// 01 · The Brief

What You're Researching

Claude is Anthropic's flagship AI assistant — and it is fundamentally different from GPT, Gemini, and every other LLM in the market. Not just in capability, but in design philosophy, safety architecture, model family structure, and how it handles nuance. Understanding that difference is not optional for anyone working in AI at Tekravio.

You will research Claude end-to-end: its philosophy, every model in its current family, every key feature, how each feature actually works under the hood (in plain English), and where Claude genuinely beats the competition — and where it doesn't. Be honest. We respect honesty over hype.

// The Golden Standard
Your final document should be readable by a non-technical Tekravio client and a senior engineer simultaneously. That means: clear language, no unnecessary jargon, honest comparisons, and specific enough detail that an engineer could actually act on it.
// 02 · The Tasks

Seven Research Modules

Each module is a standalone deliverable. All seven combined form your final research document.

01
Anthropic's Philosophy — Why Claude Is Built Different
// 12 marks · The foundation

Before you understand Claude, you must understand Anthropic. This section is about the why — the belief system that shapes every decision in Claude's design. Most people skip this. Don't.

✦
Constitutional AI (CAI): What is it, how does it work, and why did Anthropic invent it? Explain the self-critique loop in plain terms — how Claude is trained to evaluate its own responses against a "constitution" of principles.
✦
Anthropic's mission: "The responsible development and maintenance of advanced AI for the long-term benefit of humanity." What does this actually mean in practice? How does it differ from OpenAI's stated mission? Be specific, not vague.
✦
Helpful · Harmless · Honest: These are Claude's three core design values. Explain each one with a concrete example of how it manifests in Claude's real behaviour — not just theory.
✦
Why "safety" is a product feature, not a restriction: Anthropic argues that safe AI is more useful, not less. Document the evidence for this. Where does Claude's safety-first approach actually make it better at tasks? Where does it sometimes limit it?
✦
RLHF vs CAI: How does Constitutional AI training differ from standard RLHF (used by GPT)? What does Claude learn from that no other model does? Keep it technical enough to be accurate but accessible enough to explain to a client.
02
The Claude Model Family — Every Tier, In Detail
// 20 marks · The product map

Claude is not one model — it is a family. Each tier exists for a specific reason. Document every current model in the Claude family with complete accuracy. Research and update if anything has changed since your knowledge cutoff.

🚀 Claude Opus // Frontier
⚡ Claude Sonnet // Balanced
🔵 Claude Haiku // Fast & Lean

What it's NOT good at: Be honest. Where does this tier fall short? When should you pick a different tier or a different model entirely?
✦
Decision guide: A single-sentence rule for when to reach for this model. "Use Haiku when ___. Use Sonnet when ___. Use Opus when ___."

Claude is available in several very different ways. Each access method unlocks different capabilities, has different limits, and suits different users. Document every way to access Claude and what each unlocks.

✦
Pro plan: Exact pricing, model access, usage limits vs free. What does "priority access" actually mean during peak hours?
✦
Team plan: Pricing per seat, admin controls, what collaboration features exist, how it differs from Pro for a 10-person startup.
✦
Enterprise plan: What's in enterprise that isn't in Team? SSO, audit logs, data retention policies, custom fine-tuning, dedicated support. Who is this actually for?
// Anthropic API (Developer / Builder)
✦
API access: How does API pricing work vs claude.ai plans? When is API cheaper than Pro? When is it more expensive?
✦

✦
Batch API: What is the Batch API? How much does it save vs standard API? What's the trade-off (latency)? Give a real cost comparison.
